# 期待ターン数関数 T* — 数学的定義

カードゲームの対局 AI が必要とする「目標集合への最適期待到達ターン数」を、ゲーム実装に依存せず**自己完結**に
定義する。この文書だけを持ち出せば、近似手法の研究を別リポジトリで完結できることを目的とする。本書は
**実ゲームにおける期待ターン数**（概念）・**期待ターン数関数 T***（厳密に定義される数学的対象）・
**ヒューリスティック期待ターン数関数 T̂**（研究対象となる近似）の三つを明確に区別する（§1）。

---

## 1. 三つの概念

### 1.1 実ゲームにおける期待ターン数

実対局のある局面から、勝負手（目標集合に属する盤面）を作るまでに要するターン数の期待値、という**概念**。
実ゲームでは

- 山札が**均一でない**（消費とともに色構成が偏り、ドローの分布が時間変化する）、
- **他者からの贈り物**があり、自分の行動以外でも盤面に札が積まれる、
- スロットの**深さに制限が無い**。

さらに相手の方策にも依存するため、これを単独の閉じた関数として定義することはしない。本書では、T* が
近似しようとしている背後の概念としてのみ参照する。

### 1.2 期待ターン数関数 T*

実ゲームに次の **3 つの制限**を課した理想化ゲームの上で、厳密に定義される関数。本書の主対象であり、
§3〜§8 で完全に定義する。

| # | 制限 | 内容 |
|---|---|---|
| (i) | 山札は均一 | めくられる札は常に**独立・各色等確率**（一様 i.i.d.）。有限の山札・捨札という状態を持たない。ターンごとの 2 枚ドロー（§7）も連鎖サブゲーム内のドロー（§5）も同様 |
| (ii) | 他者からの贈り物なし | 盤面はプレイヤー自身の行動によってのみ変化する |
| (iii) | スロットの深さ ≤ 6 | 各スロットは上から K 枚（K ≤ 6）のみ保持し、あふれた最下段は失われる（§4） |

**これ以外に実ゲームとの差は無い**。毎ターン 2 枚を配置する規則、発火条件、連鎖の解決、得点、連鎖中の
追加アクションは、すべて実ゲームと同一である。

### 1.3 ヒューリスティック期待ターン数関数 T̂

T* を安価に近似する関数。**その設計（状態の縮約・探索・解析式・学習など）こそが研究対象**であり、本書では
決定しない。本書が定めるのは入出力の契約・研究目標・評価基準のみ（§9）。

---

## 2. 問題の一言定義

> 確率的に 2 枚ずつ与えられるカードを盤面に積んでいき、**目標集合 G に属する盤面を作るまでの
> 期待ターン数を最小化**する制御マルコフ連鎖（吸収目標つき確率的最短路, SSP）の、
> 最適値関数 T* を**安価に近似**せよ。

- 厳密解は小インスタンスでのみ計算可能（値反復）。実サイズでは状態数 ~10^17 で不可能。
- 近似関数 T̂ は対局 AI の中で 1 手あたり 10²〜10³ 回呼ばれるため、1 呼び出しはミリ秒級である必要がある。

---

## 3. パラメータと記号

### 3.1 インスタンスのパラメータ

| 記号 | 意味 | ベンチ小盤面 | 実サイズ |
|---|---|---|---|
| `m` | 色数 | 2 | 5 |
| `L` | スロット数 | 5 | 5 |
| `K` | スロットの深さ上限（≤ 6） | 2 | 6 |
| `V` | 目標点数（1 ターンの連鎖で取る点） | 3 | 20 |
| `P` | 目標確率の閾値 | 1 | 任意（調整対象） |

制限 (i)（山札均一）により山札という状態は存在せず、すべてのドロー — ターンごとの 2 枚（§7）も
連鎖サブゲーム内の 1 枚（§5）も — は独立に各色等確率 `1/m` で色が決まる。

### 3.2 主要記号の早見表

| 記号 | 意味 | 定義 |
|---|---|---|
| `C` / `S` | 色の集合 / 状態空間（盤面全体の集合） | §4 |
| `s`, `s_j` | 盤面と、そのスロット j のスタック | §4 |
| `push(s,j,c)` | スロット j に色 c を 1 枚積む（深さ制限つき） | §4 |
| `fire(s)` | 発火条件（同色の最上段が 3 枚以上） | §5.1 |
| `q(s)` | 連鎖成功確率（発火盤面 s から V 点以上を取る最大確率） | §5.4 |
| `G` / `F` / `N` | 目標 (Goal) / 失敗 (Fail) / 通常 (Normal) の状態集合 | §6 |
| `ω` | 1 ターンに与えられる 2 枚の色の組（非順序対） | §7 |
| `δ` | ω の配置（置く順序と置き先スロットの選択） | §7 |
| `T*(s)` | 期待ターン数関数（厳密な最適値） | §8 |
| `T̂(s)` | ヒューリスティック期待ターン数関数（T* の近似） | §9 |

節内でのみ使う補助記号（`top`・`tops`・`base`・`bonus`・`cost`・`A(s,ω)` など）は各定義箇所を参照。
記法の規約: `*` は「最適方策の下での厳密値」、`^`（ハット）は「その近似」。関数・集合はすべて、明示しない
限りインスタンスのパラメータ `(m, L, K, V, P)` に暗黙に依存する。

## 4. 盤面と状態空間

- 色の集合 `C = {1,…,m}`。**スタック**は C 上の長さ ≤ K の有限列（下→上）。
- **盤面** `s = (s_1,…,s_L)`、各 `s_j ∈ C^{≤K}`。状態空間 `S = (C^{≤K})^L`。
  `|C^{≤K}| = Σ_{l=0}^{K} m^l` なので `|S| = (Σ_{l=0}^{K} m^l)^L`。
  - ベンチ: `(2^0+2^1+2^2)^5 = 7^5 = 16807`。
  - 実サイズ: `((5^7−1)/4)^5 = 19531^5 ≈ 2.8×10^21`（色 5!・スロット 5! の対称性で割っても ≈ 2×10^17）。
- `top(s_j)` = スタック最上段の色（空なら未定義）。
- **深さ制限つき配置** `push(s, j, c)`：スロット j の上に c を積み、長さが K を超えたら**最下段を 1 枚捨てて**
  上から K 枚を保つ（制限 (iii)。捨てられた札は以後の力学に関与しない）。

---

## 5. 発火と連鎖サブゲーム（連鎖成功確率 q の定義）

T* の目標集合 G は連鎖成功確率 q を使って定義されるため、まず q を完全に定義する。

### 5.1 発火条件

色 c について `tops(s,c) = #{ j : top(s_j) = c }` とする。

```
fire(s) ⟺ ∃c ∈ C : tops(s,c) ≥ 3
```

### 5.2 得点

- コンボ 1 本のサイズ k（= そのとき除去された同色 top の枚数, 3 ≤ k ≤ L）の基礎点:
  `base(3)=1, base(4)=3, base(5)=10`。
- ターン内のコンボ総本数 n に対する本数ボーナス: `bonus(n) = n(n−1)/2`。
- **ターン得点** = `Σ_i base(k_i) + bonus(n)`。base・bonus とも単調増加なので「得点 ≥ V に達したら即成功」と
  短絡できる。

### 5.3 サブゲームの力学

発火している盤面 s を初期状態として:

1. **解決**: `tops(s,c) ≥ 3` を満たす**すべての**色 c について同時に、該当スロットの最上段 1 枚ずつ
   （計 `tops(s,c)` 枚）を除去する。各色が 1 本のコンボ（サイズ = 除去枚数）。除去された札は**盤面から
   消える**（復活しない）。得点・本数を加算し、`得点 ≥ V` なら**成功で終了**。
2. **追加アクション**（プレイヤーの制御点）。次のいずれか **一方**:
   - **削除**: 任意のスロットの最上段 1 枚を除去する（下層が露出する）。
   - **ドロー & 配置**: 各色等確率 `1/m` で 1 枚引き、色を見てから任意のスロットへ `push` で積む。
3. 手番 1. へ戻る。**1. で発火が無ければサブゲーム終了**（得点確定）。

### 5.4 連鎖成功確率 q

追加アクションの選び方（方策 π）に対して、

```
q(s) = max_π  Pr_π( ターン得点 ≥ V | 発火盤面 s から開始 )
```

と定める（q も他の記号と同様、インスタンスのパラメータ — 特に V — に暗黙に依存する）。

サブゲームが続く限り、1 周ごとに解決で 3 枚以上が除去され、追加アクションでの増加は高々 1 枚なので、
盤面の総札数は 1 周あたり正味 2 枚以上減る。よってサブゲームは**有限**であり、q は後退帰納（期待値 DP）で
**厳密に計算できる**。DP の状態は（盤面, コンボ本数, 基礎点合計）— 制限 (i) により山札・捨札という状態を
持たないため、これだけで閉じる（計算量上の利点）。

---

## 6. 目標集合 G と失敗集合 F

```
G = { s ∈ S : fire(s) ∧ q(s) ≥ P }     （勝負手＝ここに入ったら成功）
F = { s ∈ S : fire(s) ∧ q(s) < P }     （小発火＝仕込みを浪費する失敗）
N = { s ∈ S : ¬fire(s) }               （積み増し中の通常状態）
```

制限 (i)（山札均一）により q は盤面のみで決まり、そこまでの履歴に依存しない。よって G・F・N は
S の固定された分割である。

---

## 7. ターン遷移

毎ターン、色の**非順序対** `ω`（2 枚の色の組。同色も可）が与えられる。制限 (i) により、2 枚は
**独立に各色等確率** `1/m` で決まる:

```
Pr(ω = {c,c}) = 1/m²,    Pr(ω = {c,c′}) = 2/m²   (c ≠ c′)
```

プレイヤーは**置く順序と置き先スロット**を選ぶ。すなわち配置 `δ` とは、ω の 2 枚を置く順に並べた列
`(u, v)`（`{u, v} = ω`）と、置き先スロット `j₁, j₂ ∈ {1,…,L}` の選択であり、次状態は

```
s'(s, δ, ω) = push( push(s, j₁, u), j₂, v )
```

- **中間盤面（1 枚目を置いた直後）では発火判定をしない**。発火判定は 2 枚置き終えた s' に対してのみ行う
  （実ゲームの「保留カードを置き終えるまで解決に入らない」規則の転写）。
- 同一スロットに 2 枚重ねる場合（j₁ = j₂）、**u と v のどちらを先に置くかで結果が異なる**ため、順序は
  本質的な選択変数である。

## 8. T* の定義（ベルマン方程式）

配置 δ の即時コストを

```
cost(s') = 0        （s' ∈ G ： このターンで目標到達）
cost(s') = T*(s')   （s' ∈ N ： 積み増し継続）
s' ∈ F は選択禁止   （小発火＝失敗であり、許容されない）
```

とし、許容（admissible）な配置の集合を `A(s,ω) = { δ : s'(s,δ,ω) ∉ F }` とする。T* は次の不動点:

```
T*(s) = 0                                                （s ∈ G）
T*(s) = 1 + Σ_ω Pr(ω) · min_{δ ∈ A(s,ω)} cost(s'(s,δ,ω))   （s ∈ N）
```

- `A(s,ω) = ∅` のときは `min = +∞`（その ω では必ず小発火してしまう＝その枝は失敗）。
- F に属する s を初期状態とする値は定義しない（研究対象は N 上の T* のみ。精度評価も N 上でのみ行う）。
- これは目標集合 G を吸収状態とする**確率的最短路（SSP）**であり、適切な方策（proper policy）が存在する
  インスタンスでは値反復が一意解に収束する。

### 8.1 有限性（well-posedness）

- **ベンチ小盤面**（m=2, K=2, V=3, P=1）: 値反復が収束し、評価対象の全状態で T* < ∞ を実測済み。
- **実サイズ（V=20）**: 適切に積めば q = 1 となる G の盤面（発火すれば確定で V 点以上。主に削除による
  決定的連鎖）が多数存在し、一様 i.i.d. ドローはどの色も無限回もたらすので、どの状態からも確率 1 で G を
  組める。よって T* は全状態で有限。

### 8.2 対称性

- **スロット置換**: T* は任意のスロットの並べ替えで不変（L! 重複）。
- **色置換**: 制限 (i) によりドローは色対称なので、T* は任意の色置換で不変（m! 重複）。

## 9. ヒューリスティック期待ターン数関数 T̂（研究課題）

**入力** インスタンス `(m, L, K, V, P)` と状態 `s ∈ N`。
**出力** `T̂(s) ≈ T*(s)`。

T̂ をどう構成するか — どのような状態縮約・探索・解析式・学習を用いるか — は**本書では定めない**。
それ自体が研究対象である。本書が固定するのは入出力契約・研究目標・評価基準のみ。

### 9.1 研究目標

1. **第一目標**: `(m, L, K, V) = (5, 5, 6, 20)`（実サイズ）に固定し、**P のみ任意の入力**とした
   期待ターン数関数を近似すること。すなわち `T̂(s, P)` の形（P は対局 AI 側で調整される値であり、
   特定の P への合わせ込みでは足りない）。
2. **発展目標**: より複雑な構成が可能なら、さらに **V も任意の入力**とした `T̂(s, V, P)` に拡張できると
   望ましい。第一目標の達成を前提とする加点要素であり、必須ではない。

### 9.2 評価基準

| 評価軸 | 内容 |
|---|---|
| 精度 | 小インスタンスの厳密 T*（値反復）に対する MAE・相関で測る |
| 速度 | 対局 AI 内で 1 手あたり 10²〜10³ 回呼ばれる。1 呼び出しミリ秒級 |
| 汎化 | P を動かしても一様に機能すること（発展目標では V も）。また精度検証は厳密解の得られる小インスタンスでしか行えないため、小インスタンスから実サイズへ持ち越せる構成であること（実サイズでは厳密教師が作れず、per-インスタンス学習は成立しない） |

### 9.3 参考: 既存の到達点（設計を規定しない）

ベンチ小盤面の N 上の全状態に対し **MAE 0.012・相関 0.99** を達成する近似が存在する
（単色貪欲の解析推定と浅い後退帰納の併用。§10 の参照実装）。これは出発点となるベースラインであり、
T̂ の設計をこの形に限定する意図はない。

### 9.4 実証済みの行き止まり

- **厳密値反復の実サイズ適用**: 状態数 ~10^17 で不可能（到達閉包の発散も実測）。
- **教師あり学習**（厳密 T* をラベルに色/スロット対称特徴のリッジ回帰・MLP）: 同一インスタンス内の残差改善は
  あるが**インスタンス（色数）をまたぐ汎化が無く**、解析的ヒューリスティックの方が良く汎化する。
- **順序を捨てる状態縮約**: スタックの順序は連鎖力学（最上段除去で下層露出）に本質的であり、順序非依存の
  抽象化は精度を失う。
