# 期待ターン数 T* — 厳密定義（研究対象の数学的仕様）

GRM（`ai/REACHABILITY.md`）の外側関数 U が近似しようとしている量 **T*（目標集合への最適期待到達ターン数）** を、
ゲーム実装に依存せず**自己完結**に定義する。この文書だけを持ち出せば、近似手法の研究を別リポジトリで完結できる
ことを目的とする。実装上の唯一の正は厳密ベンチ `ai/scripts/_tstar-bench.ts`（値反復）であり、本書はその数学的
転写である。

---

## 1. 問題の一言定義

> 確率的に 2 枚ずつ与えられるカードを盤面に積んでいき、**目標集合 𝒢 に属する盤面を作るまでの
> 期待ターン数を最小化**する制御マルコフ連鎖（吸収目標つき確率的最短路, SSP）の、
> 最適値関数 T* を**安価に近似**せよ。

- 厳密解は小インスタンスでのみ計算可能（値反復）。実サイズでは状態数 ~10^17 で不可能。
- 近似関数 Û は対局 AI の内側で 1 手あたり 10²〜10³ 回呼ばれるため、1 呼び出しはミリ秒級である必要がある。

---

## 2. インスタンスのパラメータ

| 記号 | 意味 | ベンチ小盤面 | 実ゲーム |
|---|---|---|---|
| `m` | 色数 | 2 | 5 |
| `L` | スロット数 | 5 | 5 |
| `K` | 各スロットの状態表現の深さ（上から K 枚） | 2 | 6 |
| `V` | 目標点数（1 ターンの連鎖で取る点） | 3 | 20 |
| `P` | 目標確率の閾値 | 1 | ≈0.8（調整対象） |
| `D₀` | 内側サブゲーム用の山札色構成（個数ベクトル ∈ ℕ^m） | (50,50) | 各色 24 から逆算した残数 |
| `d` | 外側ドローの色分布。`d_c = D₀_c / Σ D₀` | (1/2, 1/2) | 山札+捨札の色割合 |

## 3. 盤面と状態空間

- 色の集合 `C = {1,…,m}`。**スタック**は C 上の長さ ≤ K の有限列（下→上）。
- **盤面** `s = (s_1,…,s_L)`、各 `s_j ∈ C^{≤K}`。状態空間 `S = (C^{≤K})^L`。
  `|C^{≤K}| = Σ_{l=0}^{K} m^l` なので `|S| = (Σ_{l=0}^{K} m^l)^L`。
  - ベンチ: `(2^0+2^1+2^2)^5 = 7^5 = 16807`。
  - 実サイズ: `((5^7−1)/4)^5 = 19531^5 ≈ 2.8×10^21`（色 5!・スロット 5! の対称性で割っても ≈ 2×10^17）。
- `top(s_j)` = スタック最上段の色（空なら未定義）。
- **K 切詰めつき配置** `push_K(s, j, c)`：スロット j の上に c を積み、長さが K を超えたら**最下段を 1 枚捨てて**
  上から K 枚を保つ（状態抽象化。捨てられた札は以後の力学に関与しない）。

---

## 4. 発火と連鎖サブゲーム（内側関数 f の定義）

T* の目標集合 𝒢 は内側関数 f で定義されるため、f も完全に定義する。

### 4.1 発火条件

色 c について `tops(s,c) = #{ j : top(s_j) = c }` とする。

```
fire(s) ⟺ ∃c ∈ C : tops(s,c) ≥ 3
```

### 4.2 得点

- コンボ 1 本のサイズ k（= そのとき除去された同色 top の枚数, 3 ≤ k ≤ L）の基礎点:
  `base(3)=1, base(4)=3, base(5)=10`（一般式は k≥6 で `10+(k−5)·5` だが L=5 では生じない）。
- ターン内のコンボ総本数 n に対する本数ボーナス: `bonus(n) = n(n−1)/2`。
- **ターン得点** = `Σ_i base(k_i) + bonus(n)`。base・bonus とも単調増加なので「得点 ≥ V に達したら即成功」と
  短絡できる。

### 4.3 サブゲームの力学

発火している盤面 s、山札構成 `D ∈ ℕ^m`、捨札構成 `E ∈ ℕ^m` を初期状態として:

1. **解決**: `tops(s,c) ≥ 3` を満たす**すべての**色 c について同時に、該当スロットの最上段 1 枚ずつ
   （計 `tops(s,c)` 枚）を除去する。各色が 1 本のコンボ（サイズ = 除去枚数）。除去された札は**ゲーム外**へ
   （D にも E にも入らない）。得点・本数を加算し、`得点 ≥ V` なら**成功で終了**。
2. **追加アクション**（プレイヤーの制御点）。次のいずれか **一方**:
   - **削除**: 任意のスロットの最上段 1 枚を除去し、**E に加える**（下層が露出する）。
   - **ドロー & 配置**: D から 1 枚を**非復元一様**（色 c を確率 `D_c / ΣD` で）引き、`D_c ← D_c−1`。
     任意のスロットへ `push_K` で積む。`ΣD = 0` のときは先に **E を新しい山札にする**（`D ← E, E ← 0`）。
3. 手番 1. へ戻る。**1. で発火が無ければサブゲーム終了**（得点確定）。また 2. で**両アクションとも不能**
   （`ΣD = ΣE = 0` かつ盤面が空）なら強制終了。

### 4.4 f の定義

追加アクションの選び方（方策 π）に対して、

```
f(s, V; D, E) = max_π  Pr_π( ターン得点 ≥ V | 発火盤面 s から開始 )
```

除去で盤面は単調に減り、ドローも有限なのでサブゲームは**有限**であり、f は後退帰納（期待値 DP）で
**厳密に計算できる**。DP の状態は（盤面, コンボ本数, 基礎点合計, D, E）。参照実装は
`src/ai/grmReachF.ts`（`createChainSolver`）で、実ゲームエンジンを独立オラクルとするテストで検証済み。

## 5. 目標集合 𝒢 と失敗集合 F

```
𝒢 = { s ∈ S : fire(s) ∧ f(s, V; D₀, 0) ≥ P }     （勝負手＝ここに入ったら成功）
F  = { s ∈ S : fire(s) ∧ f(s, V; D₀, 0) < P }     （小発火＝仕込みを浪費する失敗）
N  = { s ∈ S : ¬fire(s) }                          （積み増し中の通常状態）
```

注意: 𝒢 の判定に使う山札は**毎回 D₀ にリセット**する（定常近似）。これが本問題の i.i.d. モデルの一部である。

---

## 6. ターン遷移（i.i.d. 2 枚モデル）

毎ターン、色の組 `ω = {c₁, c₂}`（非順序対）が **d から i.i.d. に 2 枚**与えられる:

```
Pr(ω = {a,a}) = d_a²,    Pr(ω = {a,b}) = 2 d_a d_b   (a ≠ b)
```

プレイヤーは**置く順序とスロット**を選ぶ。配置 `δ = (順序 π, スロット a, スロット b)` に対し

```
s' = push_K( push_K(s, a, c_{π(1)}), b, c_{π(2)} )
```

- **中間盤面（1 枚目を置いた直後）では発火判定をしない**。発火判定は 2 枚置き終えた s' に対してのみ行う
  （実ゲームの「保留カードを置き終えるまで解決に入らない」規則の転写）。
- 同一スロットに 2 枚重ねる場合（a = b）、**順序 π で結果が異なる**ため、順序は本質的な選択変数である。
- 山札の消費・リシャッフルは外側では追わない（毎ターン同じ d から引く＝定常近似）。2 枚未満への縮退も無い。

---

## 7. T* の定義（ベルマン方程式）

配置 δ の即時コストを

```
cost(s') = 0        （s' ∈ 𝒢 ： このターンで目標到達）
cost(s') = T*(s')   （s' ∈ N ： 積み増し継続）
s' ∈ F は選択禁止   （小発火は許容しない＝admissible でない）
```

とし、admissible な配置の集合を `A(s,ω) = { δ : s'(s,δ,ω) ∉ F }` とする。T* は次の不動点:

```
T*(s) = 0                                                （s ∈ 𝒢）
T*(s) = 1 + Σ_ω Pr(ω) · min_{δ ∈ A(s,ω)} cost(s'(s,δ,ω))   （s ∈ N）
```

- `A(s,ω) = ∅` のときは `min = +∞`（その ω では必ず小発火してしまう＝その枝は失敗）。
- F に属する s を初期状態とする値は定義しない（研究対象は N 上の T* のみ。ベンチも N 上でのみ比較する）。
- これは目標集合 𝒢 を吸収状態とする**確率的最短路（SSP）**であり、適切な方策（proper policy）が存在する
  インスタンスでは値反復が一意解に収束する。

### 7.1 有限性（well-posedness）

- **ベンチ小盤面**（m=2, K=2, V=3, P=1, d 一様）: 値反復が収束し、評価対象の全状態で T* < ∞ を実測済み。
- **実サイズ（V=20）**: 適切に積めば f = 1 の 𝒢（発火すれば確定で V 点以上。主に削除による決定的連鎖）が多数
  存在し、i.i.d. ドローは `d_c > 0` の色を無限回もたらすので、どの状態からも確率 1 で 𝒢 を組める。
  色分布の偏りは到達ターン数を増やすだけで到達可能性は損なわない。よって T* は全状態で有限（`ai/REACHABILITY.md`
  §6.1.1）。

### 7.2 対称性

- **スロット置換**: T* は任意のスロットの並べ替えで不変（L! 重複）。
- **色置換**: `(d, D₀)` を保つ色の置換 σ に対し `T*(σ(s)) = T*(s)`。d が一様なら任意の置換で不変（m! 重複）。

## 8. 研究課題（近似関数の契約）

**入力** インスタンス `(m, L, K, V, P, D₀)` と状態 `s ∈ N`。
**出力** `Û(s) ≈ T*(s)`。

| 要件 | 内容 |
|---|---|
| 精度 | 小インスタンスの厳密 T*（値反復）に対する MAE・相関で測る |
| 速度 | 対局 AI 内で 1 手あたり 10²〜10³ 回呼ばれる。1 呼び出しミリ秒級（f の呼び出し回数が支配的） |
| 順序依存の尊重 | スタックの「順番を捨てる」抽象化は連鎖力学（最上段除去で下層露出）と非整合で不適 |
| 汎化 | インスタンス（m, K, V）をまたいで使える形が望ましい（per-インスタンス学習は実サイズで教師が作れず不可） |

### 8.1 現行ベースライン（この近似を超えるのが研究目標）

二段ヒューリスティック（`src/ai/grmAI.ts` の `expectedTurnsToG` / 公開ラッパ `estimateTurnsToG(slots, deck, discard, {V,P,K})`）:

1. **解析推定（全域）**: 各色 c を単色貪欲に積み、厳密 f ≥ P になる最小枚数 `needed_c` を求め（上限 14 枚）、
   「毎ターン 2 枚 i.i.d.」の下で**どれか早い色が needed に達する期待ターン** `E[min_c τ_c]` を多項分布の裾で
   厳密計算（候補は上位 2 色）。
2. **深さ 1 後退帰納（解析推定 ≤ 3 ターンの近距離のみ）**: §7 のベルマン式を深さ 1 だけ実展開
   （ω は上位 3 色＋無駄引き集約、配置は順序込み、深さ上限から先は 1. で埋める）。1. を上界として min。

実測（ベンチ小盤面, 非発火・非𝒢 の全状態）: **MAE 0.012・相関 0.99**
（単色 min-of-means 式 1.84/0.66 → E[min] 化＋過剰構築抑制 0.15/0.85 → 二段構え 0.012/0.99）。

### 8.2 実証済みの行き止まり

- **厳密値反復の実サイズ適用**: 状態数 ~10^17 で不可能（到達閉包の発散も実測）。
- **教師あり学習**（厳密 T* をラベルに色/スロット対称特徴のリッジ回帰・MLP）: 同一インスタンス内の残差改善は
  あるが**インスタンス（色数）をまたぐ汎化が無く**、ヒューリスティック自体の方が良く汎化する
  （`ai/CHANGELOG.md` の GRM エントリ）。

## 9. 実ゲームとの差分（この理想化で捨てているもの）

本問題は対局 AI の部品の理想化であり、以下を**意図的に**単純化している。近似研究はこの理想化モデルに対して
行えば十分（実ゲームへの接続は GRM 本体 `ai/REACHABILITY.md` §6 の責務）。

| 理想化 | 実ゲーム |
|---|---|
| 毎ターン d から i.i.d. 2 枚（山札は減らない） | 山札は消費され色構成が変わる（超幾何）。残 1 枚なら 1 枚に縮退 |
| 𝒢 判定の山札は毎回 D₀ にリセット | 発火時点の実残数で f を評価 |
| 取得は山札ドローのみ | 場の確定 2 枚ペアを取るチャネルもある（こちらは色が既知） |
| 相手・プレゼントが存在しない | 相手手番で場と山札が変わり、被プレゼントで盤面に札が増える |
| 小発火（F）は選択禁止＝必ず回避できる前提 | 実盤面でも 2 枚の置き方で通常回避可能（同条件） |
