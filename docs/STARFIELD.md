# 夜空の星のリアリティ・リファレンス

地球から肉眼で見える夜空の星の **大きさ・明るさ・色** に関する天文データと、それを
MeteoNight の背景星空（`src/components/BgStars.tsx`）へ落とし込み、**リアルな見た目**を
作るための適用設計をまとめる。

数値は末尾の出典で裏取り済み。検証外・近似は都度明記する。

---

## Part A. 天文データ

### A-1. 大きさ — 星はすべて「点」、見かけの大小は明るさの錯覚

恒星は遠すぎて角直径（見かけの直径）が極端に小さく、肉眼でも大半の望遠鏡でも
**面積を持たない点**に見える。

| 対象 | 角直径 | 備考 |
|---|---|---|
| R Doradus（太陽以外で見かけ最大級） | **約 0.057 秒角**（57ミリ秒角、別モデルで51） | これでも記録的に「大きい」星 |
| ベテルギウス | **約 0.043 秒角**（43ミリ秒角、近赤外） | 波長で 0.042〜0.069 秒角 |
| 肉眼の分解能 | **約 60 秒角（1分角）** | 最大の星でも肉眼限界の **約 1/1000 以下** |

最大級の星ですら肉眼分解能を **3 桁** 下回るため、個々の撮像望遠鏡では円盤を分解できず、
角直径測定は干渉計や恒星掩蔽でしか行えない。

**では、なぜ明るい星ほど「大きく」見えるのか** — 実体の大きさではなく光学的・知覚的な
にじみによる：

- **回折**：円形開口（瞳・レンズ）を通った光は点ではなく中央の明るい円盤＋同心円
  （**エアリーディスク**）になる。明るい星ほど裾野まで見えるので「大きく」見える。
- **大気のゆらぎ（シーイング）**：地上で像が約 1 秒角ににじみ、**またたき**（シンチレーション）が起こる。
- **眼内散乱・飽和**：明るい光ほど眼球内で散乱し、グレアとして広がる。

> **適用上の核心**：星の「大きさの違い」は実体ではなく明るさの言い換え。
> 描画では *大きいハードな円* ではなく *小さな芯＋明るさに応じた柔らかいにじみ（グロー）* で差を出すのが正しい。

### A-2. 明るさ — 暗い星ほど爆発的に数が増える

見かけの等級は **ポグソンの式** で定義される：

```
m1 − m2 = −2.5 · log10(F1 / F2)      (F = フラックス＝届く光の量)
```

- **5 等差 = ちょうど 100 倍**、**1 等差 = 100^(1/5) ≈ 2.512 倍**（暗い星ほど数値が大きい）
- 全天最輝の恒星 **シリウス = −1.46 等**（≒ −1.5）／次点カノープス −0.74 等
- **肉眼限界 ≈ 6.0 等**（良条件）〜 6.5 等（最良条件）

**等級ごとの星数分布（全天・その等級より明るい累計）**

| その等級より明るい | 星の数（全天累計） |
|---|---|
| −1.0 | 1（シリウスのみ） |
| 0.0 | 5 |
| 1.0 | 15 |
| 2.0 | 48 |
| 3.0 | 171 |
| 4.0 | 513 |
| 5.0 | 1,602 |
| 6.0 | 約 4,800 |
| 6.5 | 約 9,100〜9,500 |

読み取れること：

- **1 等級暗くなるごとに星数は約 3 倍**に増える（観測値で約 3.0〜3.5 倍。仮に宇宙が一様なら理論上 10^0.6 ≈ 3.98 倍）。
- 肉眼で見える星は全天で **約 9,000 個前後**（地平線下を除けば、ある瞬間に見えるのは約半分の 3,000 個）。
- 慣習的な「**1 等星**」（1.5 等より明るい星）は全天で **21 個**。
- → **少数のきわめて明るい星 ＋ 膨大な数の暗い星**という、強い右肩上がりの分布。

> **適用上の核心**：星の個数と明るさは一様に散らさない。「ごく少数の目立つ星＋圧倒的多数の微光星」を、
> *1 段暗くするごとに約 3 倍* の比率で積み上げるのがリアル。

### A-3. 色 — 連続分布するが、「見える色」は宇宙の真の色分布と逆さま

星の色は表面温度で決まり、高温→低温の順に **O・B・A・F・G・K・M**。定量指標が
**B−V 色指数**（小さい＝青い、大きい＝赤い）。

| 型 | 表面温度 | B−V（主系列代表値※） | 肉眼で見える実際の色 |
|---|---|---|---|
| O | ≥ 33,000 K | −0.32 | 青白 |
| B | 10,000–33,000 K | −0.30 〜 −0.16 | 青白 |
| A | 7,300–10,000 K | 0.00（A0V） | 白 |
| F | 6,000–7,300 K | 0.30 〜 0.44 | やや黄みの白 |
| **G（太陽 = G2V）** | 5,300–6,000 K | **0.65** | （ほぼ）白〜淡黄 |
| K | 3,900–5,300 K | 0.82 〜 1.15 | 橙 |
| M | 2,300–3,900 K | 1.42 〜 2.15 | 橙赤 |

※ B−V は Mamajek（ロチェスター大）の主系列星標準列より。温度境界は資料間で
±1,000〜5,000 K のばらつきあり（「おおよそ」の値）。

**重要：肉眼で見える実際の色は、教科書の色名よりずっと淡い。**
「黄色矮星」の太陽は実際は **白**、「赤色矮星」も実際は **深い橙**。
そして **緑・シアン・青紫の星は（典型的な見え方では）存在しない**（目は広い波長帯を統合するため中間色にならない）。

**宇宙の真の色分布 vs 夜空で見える色分布（← ここが最重要）**

宇宙に実在する星の個数割合（主系列星に占める割合）：

| 型 | 全主系列星に占める割合 |
|---|---|
| O | 0.00003 % |
| B | 0.12 % |
| A | 0.61 % |
| F | 3.0 % |
| G | 7.6 % |
| K | 12 % |
| **M（赤色矮星）** | **76 %** |

→ 局所実測（RECONS）でも **M 型赤色矮星が 72〜75 %**。宇宙は圧倒的に「暗くて赤い小さな星」だらけ。

**ところが肉眼で見える明るい星の色分布は正反対に偏る。** 全天最輝の約 90 星のスペクトル型内訳：

| 型 | 最輝星約 90 個中 | 例 |
|---|---|---|
| O | 3 | アルニタク、ナオス |
| **B** | **約 28（最多）** | リゲル、アクルックス |
| **A** | **約 20** | シリウス、ベガ、アルタイル |
| F | 約 8 | プロキオン、ミルファク |
| G | 約 2 | 太陽、αケンタウリ A |
| K | 約 20（多くは巨星） | アルクトゥルス、アルデバラン |
| M | 2〜3（**すべて赤色超巨星**） | ベテルギウス、アンタレス |

決定的な事実：

- 最輝星の大半は **巨星・超巨星**（光度階級 I〜III）で、本質的に明るい星ばかり。
- **赤色矮星（M 型主系列）は 1 つも肉眼で見えない**。最も明るい赤色矮星 Lacaille 8760 ですら
  **6.67 等**で肉眼限界ギリギリ〜限界下。宇宙の 76 % を占める星が夜空には事実上ゼロ。
- 肉眼で見える「赤い星」（ベテルギウス、アンタレス、アルデバラン、アルクトゥルス）は、
  数の多い赤色矮星ではなく、例外的に明るい **赤色巨星・超巨星**。

これが **観測選択効果（マルムクイストバイアス）**。明るさで足切りした標本は、遠くても見える
「本質的に明るい星」を過剰に含む。エディントンは 1914 年、肉眼星を
**「真の星の分布をまったく代表しない、きわめて特殊な抽出」** と述べた。

**もう一つの人間の視覚特性（描画に直結）**：暗所では色覚（錐体）が働かず、**暗い星は色を失って
白〜灰色に見える**。色がはっきり分かるのは明るい星だけ（プルキンエ効果／暗所視）。
→ つまり「暗い星＝白に近い、明るい星ほど色が濃く出る」。

> **適用上の核心**：
> 1. 色の主役は **青白・白**（明るい星は高温の青白星・巨星に偏る）。橙を少々、赤はごく少数（赤色巨星イメージ）。
> 2. **緑・紫は使わない**。
> 3. **彩度は明るさに比例して開く**（微光星はほぼ無彩色の白、明るい星だけに青み・橙みを乗せる）。

## Part B. 背景星空への適用設計

### B-0. 現状（`BgStars.tsx`）の要約と、リアリティ上の課題

現状は初回マウントで乱数生成（アニメーションなし）、3 集団を配置：

| 集団 | 個数 | サイズ | 不透明度 | 暖色率 |
|---|---|---|---|---|
| 全体散在（微光） | 340 | 0.6–1.6px | 0.25–0.6 | 8 % |
| クラスタ ×7（粗密） | 約 18–34 ×7 | 0.6–1.8px | 0.3–0.7 | 10 % |
| 明るい星 | 40 | 1.6–2.6px | 0.7–0.95 | 20 % |

色は白（`--rgb-white`）＋淡暖色（`--rgb-accent = #fff8c4`）の 2 色。星はハードな円
（`border-radius:50%` のべた塗り）。背景は黒＋下方からの紫グラデ。

**良い点**：タイル繰り返しを使わず継ぎ目が出ない／クラスタで粗密を作っている／初回固定で安定。

**リアリティ上の課題**（Part A と照合）：

1. **明るさ分布が平坦寄り**。3 集団のバケツ分けで、「1 段ごとに ×3」の連続的な急勾配になっていない。
2. **大きさで明るさを表現している**が、実際は *にじみ（グロー）* が明るさの正体。ハードな円のままだと「点の大小」に見えて天体らしくない。
3. **色が 2 色のみ・比率が任意**。青白がなく、彩度と明るさが連動していない。
4. **天の川・地平線減光など大局構造がない**（クラスタはランダムで、帯状の濃淡や下方減光がない）。

以下、課題ごとに具体策を示す。

### B-1. 明るさ：等級分布を個数・グロー・不透明度へ

**1 段暗くするごとに約 3 倍**（A-2）をそのまま個数に使う。3 集団のバケツではなく、
等級バンドを積み上げる連続モデルにする。例：画面に約 500 個を撒くなら

| 見かけ等級バンド（画面用） | 個数 | 役割 |
|---|---|---|
| 最輝（1 等相当） | 約 8 | 主役。明確なグロー＋色 |
| 2 等相当 | 約 22 | 目立つ星。小さめグロー＋色 |
| 3 等相当 | 約 60 | やや目立つ |
| 4 等相当 | 約 170 | 微光。芯のみ、ほぼ無彩色 |
| 5 等相当 | 約 440 | 地の星 |
| 6 等相当以下 | 約 700 | 地の星。サブピクセル級の白点 |

（暗いバンドほど約 ×3。合計 ≒ 1,400）

各星の明るさパラメータはポグソンに従い等級 `m` から導く：

```
flux  = 2.512 ^ (-(m - mBright))         // mBright = 最輝の等級。flux: 1(最輝)→小(微光)
opacity   = clamp(0.22 + 0.78 * flux^0.45, 0.18, 1)   // 知覚に合わせ緩いガンマ
coreSize  = lerp(0.6px, 2.4px, brightnessT)           // 芯は控えめに
glowRadius= brightnessT < 0.5 ? 0 : lerp(0, 14px, (brightnessT-0.5)/0.5) // 明るい星のみグロー
```

ポイント：**サイズで殴らない**。芯は最大でも 2.4px 程度に抑え、明るさの差は主に
**グローと不透明度**で出す（A-1）。

### B-2. 色：B−V → RGB、彩度は明るさで開く

2 色をやめ、B−V を淡い RGB へ写した小パレットにする。**下表は黒体色の知覚近似に基づく描画用の値**
（測定値ではない。より厳密には黒体色テーブルから引ける — 出典参照）：

| 型 / B−V | 知覚色 | 描画 RGB（実装値 = `STAR_TINTS`） | 出現比 |
|---|---|---|---|
| O・B（−0.3〜−0.1） | 青白 | `rgb(160,188,255)` = `#a0bcff` | 30 |
| A（0.0） | 白 | `rgb(245,247,255)` = `#f5f7ff` | 30 |
| F（0.3–0.45） | やや黄みの白 | `rgb(255,246,230)` = `#fff6e6` | 15 |
| G（0.65・太陽） | 白〜淡黄 | `rgb(255,241,216)` = `#fff1d8` | 8 |
| K（0.8–1.2） | 橙 | `rgb(255,206,150)` = `#ffce96` | 14 |
| M 巨星（1.4–2.0） | 橙赤 | `rgb(255,170,120)` = `#ffaa78` | 3 |

**出現比は「肉眼星の偏り」（A-3）に寄せる**：青白＋白で 60 %、橙系 22 %、橙赤はわずか 3 %。
宇宙の真の比率（M 76 %）ではなく、観測選択効果で偏った **“見えている空”の比率** を使う。
RGB は黒体色の知覚近似で、彩度は下式で明るさに連動させる（暗い星は白へ寄る）。

**彩度を明るさで開く**（A-3 の暗所視）— 微光星は色を抜いて白へ寄せ、明るい星だけ色を濃くする：

```
satT  = clamp((brightnessT - 0.35) / 0.65, 0, 1)   // 暗い星は色がほぼ出ない
color = mix(white, tint, satT)                     // tint = 上表の型別色
```

これで「地の微光星は無彩色の白、目を引く星だけ青白・橙に色づく」という、実際の夜空の見え方になる。

### B-3. 大きさ：実サイズでなく「輝きのにじみ」で

A-1 のとおり大きさの差は錯覚。描画は **小さな芯＋柔らかいグロー** に統一する：

```css
.bg-star {
  border-radius: 50%;
  /* 芯は白寄り、にじみは芯色。明るい星ほど box-shadow を広げる */
  background: radial-gradient(circle, #fff 0%, var(--star-core) 60%, transparent 100%);
  box-shadow: 0 0 var(--glow, 0) var(--star-core);
}
```

- **避けるべき**：十字の回折スパイク。あれは望遠鏡やカメラの絞り由来で、肉眼の空には出ない。
  CG・写真っぽさが出るので「空を見上げた」感には逆効果。にじみは**丸いグロー**に。
- グロー（`box-shadow`）は重いので、**明るい星（数十個）に限定**する（実装では brightnessT ≥ 0.5 の
  約 60 個。微光星 400+ は芯だけ）。500 spans でも大半が芯のみなら現行同様に軽い。

### B-4. 大局構造：天の川・地平線減光・粗密

- **天の川の帯**：画面を斜めに横切る帯に星密度を上げ、その内側に
  ごく淡い白〜青白の `radial-gradient` を数枚重ねて「光る霞」を作る（個々の星は分解せず雲のように）。
  現行の 7 クラスタを、この帯に沿って寄せると自然。
- **地平線減光**：下方（地平線側）ほど大気で減光・赤化する。下端に向けて星の不透明度を下げ、
  色をわずかに橙へ寄せる。現状の紫グラデ（`radial-gradient(... at 50% 118%)`）と整合する。
- **粗密のムラ**：現行のクラスタ方式は維持。完全な一様分布は不自然なので、粗密は残す。

### B-5. 動き：アニメーションは使用しない（方針）

またたき（シンチレーション, A-1）は実在する大気現象だが、本プロジェクトでは **アニメーションを
使用しない**。現行 `BgStars.tsx` も初回生成後は静止しており、これを維持する。
静止のままでも B-1〜B-4（明るさ分布・色・にじみ・大局構造）で十分にリアルな星空は成立する。

### B-6. まとめ — リアリティ優先順位とパラメータ早見

効果が大きい順：

1. **色（B-2）**：青白の追加＋彩度を明るさ連動。最も「天体らしさ」に効く。緑・紫は禁止。
2. **明るさ分布（B-1）**：×3/段の急勾配で「少数の主役＋多数の地の星」。
3. **にじみ（B-3）**：芯＋丸いグロー。サイズで殴らない／スパイク禁止。
4. **大局構造（B-4）**：天の川・地平線減光。

（またたき等のアニメーションは使用しない方針 — B-5 参照。）

早見表：

| 項目 | 現状 | 推奨 |
|---|---|---|
| 明るさ→個数 | 340/175/40 のバケツ | 等級バンドで約 ×3/段（8/22/60/170/440/700 ≒ 1,400） |
| 明るさ表現 | サイズ 0.6–2.6px＋不透明度 | 芯 ≤2.4px ＋ グロー（明るい星のみ）＋不透明度 |
| 芯の形 | ハードな円 | 芯＋丸い radial グロー（スパイク無し） |
| 色 | 白＋暖色の 2 色 | B−V 由来の青白〜橙赤、青白/白が大半 |
| 彩度 | 固定（暖色 8–20%） | 明るさに比例（微光星は無彩色の白） |
| 構造 | ランダム＋7 クラスタ | ＋天の川帯／地平線減光 |
| 動き | なし | なし（アニメーション不採用・方針） |

> 実装は `BgStars.tsx`（生成ロジック）＋ `index.css` の `.bg-star` 系（描画）で完結する。
> 星色は `BgStars.tsx` の `STAR_TINTS` に持ち、彩度を明るさに連動させて mix した最終色を
> CSS 変数 `--c`（とグロー量 `--glow`）として各星へ inline 付与する（`:root` のトークンは追加しない）。
