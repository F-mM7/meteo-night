**テーマ**: 5つの属性を持つ「星のかけら」を自分の場に配置し、連鎖（流星魔法）を組み上げて夜空に星を放ち、その美しさ（得点）を競う。

## 2. コンポーネント

### 星のかけらカード

- **5色（属性）**: 赤・緑・黄・紫・青
  - 動画では「青き（青）」「緑」「赤」「黄色」「紫」が確認できる
  - `[要確認]` 各色の枚数の内訳

### 個人ボード（プレイヤーごと）

- **制約スロット**: **5つ** `[要確認: 5つで合っているか]`
  - 各スロットにはカードを **積み重ねて** 配置できる
  - スロットの **一番上のカードのみが「最上段」として扱われる**（流星魔法の判定対象）
  - 下に積まれたカードは見えるが、最上段が取り除かれるまで判定に関与しない

### 場（共通エリア）

- **2枚組のカードセット × 2組** が公開で並ぶ（合計4枚が表向き）
  - `[要確認]` 何組並ぶか・補充タイミング（即時か手番終了時か）
- **山札**（裏向きの星のかけら）

### スタートプレイヤーマーカー

- 動画では「チャンネル登録ボタン」と呼ばれる円盤型マーカー

### 種族カード（アドバンスドルール用）

- 各プレイヤーに1枚配布し、特殊能力を付与する
- 詳細は **第10章「アドバンスドルール」** を参照

## 3. セットアップ

1. 星のかけらカードをよくシャッフルして山札を作る
2. 各プレイヤーの個人ボードの **5スロットそれぞれに、5色（赤・緑・黄・紫・青）を1枚ずつ配置** した状態でスタートする
   - スロット番号と色の対応は固定で良い（赤=1, 緑=2, 黄=3, 紫=4, 青=5）`[要確認: 厳密な対応順]`
3. 残りの山札の上から **2枚組 × 2組** を場に表向きで並べる
4. スタートプレイヤーを決定し、マーカーを渡す

> 動画の「最初の5枚はどう置いても対称性」という発言は、「5色1枚ずつだからどの順番で置いても結果は同じ」という意味と解釈。

## 4. 手番の流れ

各プレイヤーは時計回りに以下の手番を行う。

### ステップ1: 星のかけらを集めて配置する

以下のいずれかを選ぶ：

- **A. 場から取る**: 公開されている2枚組のうちいずれか1組（2枚）を回収する
- **B. 山札から引く**: 山札の上から裏向きで2枚を引いて回収する

回収した **2枚のカードを、自分のボードの好きなスロットの上に表向きで配置** する。

- 2枚を別々のスロットに置いてもよい
- 2枚を同じスロットに重ねて置いてもよい（その場合、どちらを下に置くかも任意に選べる）
- 既に積まれているカードの上に重ねる
- **配置する順番（どちらのカードを先に置くか）は任意に選べる**

### ステップ2: 流星魔法の発動

**同じ属性（色）の星のかけらカードが、各スロットの最上段に3枚以上揃う** と「**流星魔法**」が発動する。

- 揃った色のカード（3枚以上、最上段にあるもの全て）を **打ち上げエリア** に移動する
- これを「**星を放つ**」と表現する
- `[要確認]` 「最上段に揃う」とは、各スロットの一番上のカードを横並びで見て同色が3枚以上、という解釈。動画でもこの挙動に見える。

### ステップ3: 追加アクション（流星魔法発動ごとに強制）

流星魔法を1回発動するごとに、以下のいずれか **1つ** を必ず実行する：

- **A. 引いて配置**: 山札の上から星のかけらカードを **1枚** 引き、自分のボードの好きなスロットに配置する
- **B. 取り除いて捨札**: 自分のボードの任意のスロット最上段にあるカードを **1枚** 取り除き、捨札にする

> 動画より：「これできる時は絶対しなきゃいけない」（強制アクション）
>
> 追加ドローは山札からのランダム引き（場の公開カードからは取れない）。

### ステップ4: 連鎖判定

追加アクションの結果、再び最上段に同色3枚以上が揃ったら **連鎖** として流星魔法が再発動する。

- 連鎖が止まる（条件を満たさなくなる）まで、ステップ2-3を繰り返す
- 各連鎖が独立した「コンボ」として記録される

### ステップ5: 得点計算

そのターンに発動した流星魔法（コンボ）の合計から得点を計算する。 → **第5章「得点計算」** 参照

### ステップ6: 他プレイヤーへ星のかけらを渡す（プレゼント）

`[要確認: 動画と公式の記述に差異あり]`

- **公式概要の記述**: 「このターンに発動した流星魔法で使用したカードの中から **1枚** を選び、他のプレイヤーに渡します」
- **動画での説明**: 「それぞれのコンボから1枚ずつ他の人に渡してください」「4コンボなら4枚」

**仮実装方針（動画準拠）**: 各コンボから1枚ずつ選んで他プレイヤーに渡す。受け取ったプレイヤーは即座に自ボードの好きなスロットに配置する（拒否不可、必ず置く）。

- 渡す側のルール：
  - 各コンボにつき1枚ずつ選ぶ
  - **誰に渡すか** も選べる（特定の相手に集中させる、全員に散らす、いずれも可能）
  - 渡されたカードによって相手が連鎖発火する可能性もあるが、**相手の発火は次のその相手の手番で処理される（即時発火しない）**
    - 動画より：「他の人に放って発火した場合ってどうなんだ? え、それはその人の番が来るまでは保留」

- 受け取る側のルール：
  - 必ず自分のボードの好きなスロットに配置する（拒否・捨札にはできない）
  - 配置による発火は、その受け取りプレイヤーの次の手番開始時に処理（**保留**）`[要確認]`

### ステップ7: ターン終了

次のプレイヤーへターンを渡す。

## 5. 得点計算

### 基礎点（コンボの枚数別）

| 揃った枚数 | 基礎点 |
| --- | --- |
| 3枚 | 1点 |
| 4枚 | 3点 |
| 5枚 | 10点 |
| 6枚以上 | `[要確認]` 動画では言及なし。仮実装では「+(枚数-5)×n点」等で拡張する。 |

> 動画より：「3個の時は基礎点1点なんですけど、4個でコンボできた場合3点になります」「もし黄色が5個今揃ったとしたらそれだけで10点」

### コンボボーナス

`[要確認]` 動画では複数の事例があり、計算式が一意に定まらない。以下は **仮ルール**：

**仮案A: 基礎点合計と同額のボーナス**

- 例: 3枚×3コンボ + 4枚×1コンボ = 基礎点 1+1+1+3 = 6点 → ボーナス 6点 → **合計12点**
- 動画の一例「1+1+1+3で6点。コンボボーナスで6点入るから12点」と一致

**仮案B: コンボ数 × X 点**

- 例: 4枚×3コンボ → 基礎点 9点 + コンボ数3×1点 = **合計12点**
- 動画の一例「3点3点3点でボーナスで3点なので12点」と一致

**実装方針**: 仮案A（基礎点を倍にする）で初期実装し、後で `scoring.ts` の関数を差し替え可能にする。

### ゲーム終了トリガー

- **いずれかのプレイヤーが累計20点に達した時点で、終了フラグを立てる**
- その時点から、**スタートプレイヤーまでの1周** を消化してゲーム終了
  - 例：プレイヤーA(SP)→B→C→D の順で、Cが20点到達したら、D の手番まで実施して終了
- 動画より：「20に行ったらゲームの終了が始まります」「みんな同じ番のやったら終わりか」

### 勝者判定

- 終了時点での **最高得点者が勝利**
- **同点の場合は、ターン順（スタートプレイヤーから近い）が先のプレイヤーが勝ち**
  - 動画より：「同点の場合はターンが先の方が勝ちです」

---

## 6. 連鎖の挙動（補足）

- 連鎖は **同色3枚以上が最上段に揃う限り続く**
- 連鎖の各回ごとに **追加アクション（引く or 捨てる）が強制発生**
- 追加アクションで山札からカードを引いて配置 → そのカードで連鎖が継続する可能性あり
- 取り除く（捨札）を選ぶ場合：取り除いたことで下のカードが露出し、それで連鎖が発火する可能性あり
- 連鎖が止まったら追加アクションは行わない（連鎖が止まる＝発火条件を満たさなくなった時点で終了）

---

## 7. 他プレイヤーから渡されたカードの扱い

- 渡されたカードは **強制的に自分のボードのいずれかのスロットに配置** する（拒否不可）
- 受け取りプレイヤーは配置場所のみ選択できる
- この時の発火は **次の自分の手番開始時** に処理される `[要確認]`
- 渡されたカードを **複数枚** 受け取った場合の処理順 `[要確認]`

---

## 8. ゲーム終了と最終得点

- 終了フラグが立ったあと、スタートプレイヤーまでの1周を消化
- 各プレイヤーの最終得点を比較し、最高得点者が勝利
- 同点はターン順が早いプレイヤーの勝利

## 付録: 本Webアプリの実装方針

- **人数**: 4人（プレイヤー1人 + CPU3体）固定
- **アドバンスドルール**: 初期実装では使用しない（基本ルールのみ）。将来的に種族カードを追加可能な構造にする。
- **得点計算**: 仮案A（基礎点と同額のコンボボーナス）で実装。`src/game/scoring.ts` を差し替えれば変更可能。
- **プレゼント処理**: 動画ベース（各コンボから1枚ずつ）で実装。発火は受領者の次手番で保留。
- **ルール調整**: このRULES.mdを訂正することで、`src/game/` 配下の対応する関数を修正する想定。
