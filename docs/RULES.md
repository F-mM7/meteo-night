## 1. ゲーム概要

| プレイ人数 | 2〜5人（本Webアプリでは **1人 vs CPU3体** の4人プレイ） |

**ジャンル**: 戦略 × 連鎖 × 運 / 爽快コンボ系ボードゲーム

**テーマ**: 5つの属性を持つ「星のかけら」を自分の場に配置し、連鎖（流星魔法）を組み上げて夜空に星を放ち、その美しさ（得点）を競う。

## 2. コンポーネント

### 星のかけらカード

- **5色**: 赤・緑・紫・黄・青
- **総枚数: 推定100枚（各色20枚）** `[要確認]`
  - 公式の枚数情報が未確認のため、本実装では各色20枚×5色=計100枚と仮定
  - 4人プレイの場合：初期配置で20枚（5色×4人）+ 場に4枚 = 24枚消費、山札残76枚でスタート

### 個人ボード（プレイヤーごと）

- **制約スロット**: **5つ** 
  - 各スロットにはカードを **積み重ねて** 配置できる
  - スロットの **一番上のカードのみが「最上段」として扱われる**（流星魔法の判定対象）
  - 下に積まれたカードは見えるが、最上段が取り除かれるまで判定に関与しない

### 場（共通エリア）

- **2枚組のカードセット × 2組** が公開で並ぶ（合計4枚が表向き）
  - 何組並ぶか：２
  - 補充タイミング：手番終了時
- **山札**（裏向きの星のかけら）

### スタートプレイヤーマーカー


### 種族カード（アドバンスドルール用）

- 各プレイヤーに1枚配布し、特殊能力を付与する
- 詳細は **第10章「アドバンスドルール」** を参照

## 3. セットアップ

1. 星のかけらカードをよくシャッフルして山札を作る
2. 各プレイヤーの個人ボードの **5スロットそれぞれに、5色（赤・緑・紫・黄・青）を1枚ずつ配置** した状態でスタートする
   - スロット番号と色の対応は固定で良い（赤=1, 緑=2, 紫=3, 黄=4, 青=5）
3. 残りの山札の上から **2枚組 × 2組** を場に表向きで並べる
4. スタートプレイヤーを決定し、マーカーを渡す


---

## 4. 手番の流れ

各プレイヤーは時計回りに以下の手番を行う。

### ステップ1: 星のかけらを集めて配置する

以下のいずれかを選ぶ：

- **A. 場から取る**: 公開されている2枚組のうちいずれか1組（2枚）を回収する
  - 取られた場のスロットは **手番終了時に山札から補充** される（取得直後ではない）
- **B. 山札から引く**: 山札の上から裏向きで2枚を引いて回収する

回収した **2枚のカードを、自分のボードの好きなスロットの上に表向きで配置** する。

- 2枚を別々のスロットに置いてもよい
- 2枚を同じスロットに重ねて置いてもよい（その場合、どちらを下に置くかも任意に選べる）
- 既に積まれているカードの上に重ねる
- **配置する順番（どちらのカードを先に置くか）は任意に選べる**

### ステップ2: 流星魔法の発動

**同じ属性（色）の星のかけらカードが、各スロットの最上段に3枚以上揃う** と「**流星魔法**」が発動する。

- 揃った色のカード（3枚以上、最上段にあるもの全て）を **打ち上げエリア** に移動する
- これを「**星を放つ**」と表現する
-  「最上段に揃う」とは、各スロットの一番上のカードを横並びで見て同色が3枚以上、という意味。

### ステップ3: 追加アクション（流星魔法発動ごとに強制）

流星魔法を1回発動するごとに、以下のいずれか **1つ** を必ず実行する：

- **A. 引いて配置**: 山札の上から星のかけらカードを **1枚** 引き、自分のボードの好きなスロットに配置する。追加ドローは山札からのランダム引き（場の公開カードからは取れない）。
- **B. 取り除いて捨札**: 自分のボードの任意のスロット最上段にあるカードを **1枚** 取り除き、捨札にする


### ステップ4: 連鎖判定

追加アクションの結果、再び最上段に同色3枚以上が揃ったら **連鎖** として流星魔法が再発動する。

- 連鎖が止まる（条件を満たさなくなる）まで、ステップ2-3を繰り返す
- 各連鎖が独立した「コンボ」として記録される

### ステップ5: 得点計算

そのターンに発動した流星魔法（コンボ）の合計から得点を計算する。 → **第5章「得点計算」** 参照

### ステップ6: 他プレイヤーへ星のかけらを渡す（プレゼント）

`[要確認: 動画と公式の記述に差異あり]`

- **公式概要の記述**: 「このターンに発動した流星魔法で使用したカードの中から **1枚** を選び、他のプレイヤーに渡します」
- **動画での説明**: 「それぞれのコンボから1枚ずつ他の人に渡してください」「4コンボなら4枚」

**仮実装方針（動画準拠）**: 各コンボから1枚ずつ選んで他プレイヤーに渡す。**渡された時点で、受け取ったプレイヤーが自ボードの好きなスロットに即座に配置する**（拒否不可、必ず置く）。

- 渡す側のルール：
  - **送るカードはまとめて選択する**（連鎖した各コンボについて、どのカードを誰に渡すかを一度に決定）
  - 例：3連鎖した場合、3枚のカードそれぞれの送付先を一括で決める
  - **誰に渡すか** も選べる（特定の相手に集中させる、全員に散らす、いずれも可能）

- 受け取る側のルール：
  - **渡された時点で、自分のボードの好きなスロットに即座に配置する**
  - 配置場所は受け取り側が選ぶ（拒否・捨札にはできない）
  - **2枚以上を受け取った場合、好きな順番で配置できる**（受け取り側が配置順を選択）
  - 配置による流星魔法の発動は **起きない**（贈与配置では発火しない）

### ステップ7: ターン終了

次のプレイヤーへターンを渡す。

## 5. 得点計算

### 基礎点（コンボの枚数別）

| 揃った枚数 | 基礎点 |
| --- | --- |
| 3枚 | 1点 |
| 4枚 | 3点 |
| 5枚 | 10点 |

### コンボボーナス（連鎖回数依存）

そのターンに発動した流星魔法の **連鎖回数** に応じて、ボーナス点が加算される。基礎点の大小には依存しない。

| 連鎖回数 | ボーナス点 |
| --- | --- |
| 1回 | 0点 |
| 2回 | 1点 |
| 3回 | 3点 |
| 4回 | 6点 |
| 5回 | 10点 |

一般式: ボーナス = `n × (n − 1) / 2`（n は連鎖回数）。

- 例: 4枚×3コンボ → 基礎点 3+3+3=9点 + 3連鎖ボーナス3点 = **合計12点**
- 例: 3枚×3 + 4枚×1（=4連鎖）→ 基礎点 1+1+1+3=6点 + 4連鎖ボーナス6点 = **合計12点**


### ゲーム終了トリガー

- **いずれかのプレイヤーが累計20点に達した時点で、終了フラグを立てる**
- その時点から、**スタートプレイヤーまでの1周** を消化してゲーム終了
  - 例：プレイヤーA(SP)→B→C→D の順で、Cが20点到達したら、D の手番まで実施して終了
- 動画より：「20に行ったらゲームの終了が始まります」「みんな同じ番のやったら終わりか」

### 勝者判定

- 終了時点での **最高得点者が勝利**
- **同点の場合は、ターン順（スタートプレイヤーから近い）が先のプレイヤーが勝ち**
  - 動画より：「同点の場合はターンが先の方が勝ちです」

---

## 6. 連鎖の挙動（補足）

- 連鎖は **同色3枚以上が最上段に揃う限り続く**
- 連鎖の各回ごとに **追加アクション（引く or 捨てる）が強制発生**
- 追加アクションで山札からカードを引いて配置 → そのカードで連鎖が継続する可能性あり
- 取り除く（捨札）を選ぶ場合：取り除いたことで下のカードが露出し、それで連鎖が発火する可能性あり
- 連鎖が止まったら追加アクションは行わない（連鎖が止まる＝発火条件を満たさなくなった時点で終了）

---

## 7. 他プレイヤーから渡されたカードの扱い

- 渡されたカードは **その場で即座に自分のボードのいずれかのスロットに配置** する（拒否不可）
- 受け取りプレイヤーは配置場所のみ選択できる
- 渡された **複数枚を任意の順番で配置** できる
- 贈与配置で最上段に同色3枚以上が揃ったとしても、**そのターンでは流星魔法は発動しない**

---

## 8. ゲーム終了と最終得点

- 終了フラグが立ったあと、スタートプレイヤーまでの1周を消化
- 各プレイヤーの最終得点を比較し、最高得点者が勝利
- 同点はターン順が早いプレイヤーの勝利

## 10. アドバンスドルール（種族カード）

各プレイヤーに1枚の種族カードを配り、その能力をゲーム中適用する。

### 動画で言及された種族

| 種族名 | 効果 |
| --- | --- |
| ゴブリン | その手番の1つ目の流星魔法を発動した際の追加アクションで、山札から **1枚ではなく3枚** 引いて配置可能 |
| 安定 | 基礎ポイントが **全て +1点**（3枚=2点 / 4枚=4点 / 5枚=11点） |
| （名称不明） | 制約スロットを **4つしか使用できない** が、**基礎ポイントが2倍**（3枚=2点 / 4枚=6点 / 5枚=20点） |

> 動画より：「いっぱいいるんですよ、これ。何度やっても違う効果楽しめる」
