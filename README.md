# 星を放つ夜（MeteoNight）CPU対戦Web

RIDDLER（リドラ）が制作したボードゲーム『星を放つ夜（MeteoNight）』を、ブラウザ上でCPUと対戦できるようにしたWebアプリです。
あなた1人 vs CPU3体の4人卓を、いつでも好きなだけ遊べます。

> 本アプリは非公式のファン作品です。原作については [ゲームマーケット公式ページ](https://gamemarket.jp/game/187954) をご覧ください。

公開URL: <https://f-mm7.github.io/meteo-night/>

## このゲームについて

5色（赤・緑・黄・紫・青）の「星のかけら」カードを自分のボードに並べ、同じ色を最上段に3枚以上揃えて **流星魔法** を発動させるコンボゲームです。
連鎖を繋ぐほど得点が伸びていき、誰かが20点に到達したラウンドで決着します。

- **手番でやること**: 場の2枚組を取るか山札から2枚引いて、自分の5つのスロットに配置します。
- **流星魔法**: 各スロットの一番上に同色が3枚以上並ぶと発動。揃ったカードを夜空に放って得点になります。
- **連鎖**: 発動のたびに「山札から1枚引いて配置」か「最上段から1枚取り除く」を行い、再び同色が揃えば連鎖します。
- **プレゼント**: 連鎖で打ち上げたコンボごとに1枚を選んで、他プレイヤーに渡します。受け取った相手は自分のボードに置かなければなりません。
- **ゲーム終了**: 誰かが20点に達したラウンドの最後まで進めて、最高得点者の勝ちです（同点はターン順が先の人が勝ち）。

詳しいルールは [`docs/RULES.md`](docs/RULES.md) にまとめています。

## 画面の使い方

ページ上部のヘッダーから、ゲームの進行に関わるいくつかの設定を切り替えられます。

- **演出ディレイ (ms)**: 1手ごとに挟む演出の待ち時間です。CPUの思考速度そのものではなく表示テンポの調整で、小さくすると展開が速くなり、大きくするとじっくり追えます。
- **観戦モード**: ONにすると、自分の手番もCPUが代わりに打ちます。試合全体の流れを眺めたいときに便利です。
- **ログ表示 / 非表示**: 画面右側のプレイログを開閉します。「誰が何を取って、どう連鎖したか」を後から確認できます。
- **新規ゲーム**: いつでも押すと、その場で新しい卓を始められます。

手番中は、場に表向きで並んだ2枚組か中央の山札のどちらかをクリックして2枚を引き、続けて自分のボードのスロットをクリックして配置します。連鎖中の追加アクションや、コンボで他プレイヤーに渡すカードの選択も、画面の指示に従って選んでいくだけで進みます。
